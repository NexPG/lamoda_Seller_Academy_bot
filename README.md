AI RAG Agent, который отвечает на вопросы связанные с Lamoda seller academy.
Agent построен на базе Gemini (Требуется API KEY), есть отдельный notebook который парсит всю актуальную базу знаний с оф сайта Lamoda Seller Academy.
Реализован гибридный ретривер, который делит всю базу знаний на чанки, а потом двумя методами (sparce и dense) ищет самые подходящие чанки, котоыре по итогу попадут в LLM для ответа.
Gemini генерирует 3 запроса основаных на запросе пользователя, эти 3 запроса отправляются ретриверу. LLM по итогу может получить до 30 чанков из базы занний.
Ответ от агента выводятся четкой структурой, показывается какие запросы были отправлены ретриверу и сколько ответов ретривер нашел на каждый из запросов, и общее количество уникальных чанков. В конце ответа выводятся все статьи с ссылками, из которых были взяты чанки.
