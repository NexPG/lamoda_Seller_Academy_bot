# Lamoda Seller Academy AI RAG Agent

Умный ИИ-ассистент на базе архитектуры **RAG (Retrieval-Augmented Generation)**, разработанный для точных и быстрых ответов на вопросы партнеров маркетплейса Lamoda. 

Агент работает строго по официальной базе знаний. Для генерации ответов используется семейство моделей **Gemini** (требуется API-ключ).

---

## Ключевые особенности проекта

* **Автоматический парсинг данных:** В состав проекта входит отдельный ноутбук, который собирает, структурирует и сохраняет всю актуальную базу знаний с официального сайта Lamoda Seller Academy.
* **Гибридный ретривер (Hybrid Retriever):** База знаний делится на небольшие смысловые куски (чанки). Поиск нужной информации идет одновременно двумя методами:
  * **Sparse** (лексический поиск) — ищет точные совпадения слов с учетом русской морфологии.
  * **Dense** (семантический поиск) — улавливает скрытый смысл вопроса, даже если слова сформулированы иначе.
* **Расширение запросов (Multi-Query Expansion):** На основе одного вопроса пользователя Gemini генерирует 3 разных по формулировке поисковых трека. Это позволяет «подцепить» нужные документы, даже если пользователь спросил размыто.
* **Умная дедупликация:** Ретривер собирает до 30 потенциально полезных чанков, после чего алгоритм автоматически отсекает дубликаты, оставляя только уникальный контекст.
* **Абсолютная прозрачность под капотом:** Агент детально логирует свою работу в консоль в реальном времени.

---

## 📊 Формат вывода в консоль

Ответ агента имеет строгую и понятную структуру:
1. Исходный вопрос пользователя.
2. Список из 3 сгенерированных поисковых запросов.
3. Количество зацепленных ответов по каждому из запросов отдельно.
4. Итоговое количество уникальных чанков, которые пошли на вход LLM.
5. Человечный, структурированный ответ на вопрос.
6. Блок первоисточников в самом конце (название статьи, кликабельная ссылка и дата последнего обновления из метаданных).
